# ADR-0002: ESP32 (M5StickC Plus2) は ESP-IDF で開発する

**ステータス:** Active | **日付:** 2026-09-27

### 問い
ESP32 の開発フレームワークには Arduino と ESP-IDF がある。どちらを採用するか。

### 検討した選択肢
- **A: `Arduino Core`** — ②③を満たせないため落とした
- **B: `ESP-IDF`** ← 採用
- **C: `Arduino / ESP-IDF 両方`** — 過度に複雑になるため落とした

### 決定と決め手

前提として、どの手法でも ① micro-ROS を実装できること が実現できる。

その上で、以下の観点で比較した。

② アーキテクチャ設計の自由度が高いこと
③ 組み込み開発の経験を積むことができること (ADR0001)
    * FreeRTOS のタスク設計できること
    * ESP32 のメモリ管理を理解できること

②③をすべて満たすのはBのみ。特に③はADR-0001で定めた学習目的に直結するため、立ち上がりの遅さを許容してBとした

### 影響

Arduino ライブラリを使用できないため、M5 の実装例を ESP-IDF に置き換える作業が発生する。
